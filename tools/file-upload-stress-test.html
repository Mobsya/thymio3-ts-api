2. Configure the barrage

Uploads run one at a time, as fast as the robot acknowledges them. Generated files stay in RAM; this test does not save or erase files in storage.

The upload timer restarts after each completed packet, so a large file can take longer than this. Setup and RAM cleanup use this value as their operation deadline. The defaults cover small files, packet boundaries at the 500-byte write limit, and larger transfers. Sizes may range from 0 to 1,048,576 bytes. Compare Off and All sensors using the same sizes and seed. Streaming starts before uploads, stays enabled throughout the run, and stops afterward. Each selected stream must deliver data before uploads begin.

Keeping the same sizes and seed reproduces the generated bytes. Disconnections and unconfirmed transfers always stop the run. A stalled operation requires a page reload.
